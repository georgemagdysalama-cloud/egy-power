## نظرة عامة

موقع تعريفي احترافي لشركة **Egy Power** متخصص في توريد الخامات والمستلزمات الكهربائية للمشروعات والمقاولات. الموقع ثنائي اللغة (عربي/إنجليزي) مع دعم RTL، بهوية بصرية زرقاء احترافية تعكس مجال الطاقة والكهرباء.

## الصفحات (Routes منفصلة)

1. **الرئيسية** `/` — Hero بارز + نبذة + أبرز المنتجات + المميزات + CTA للتواصل
2. **من نحن** `/about` — قصة الشركة، الرؤية، الرسالة، القيم
3. **المنتجات** `/products` — عرض فئات المنتجات:
   - مواسير كهربائية EMT و RSC
   - فلكسبل
   - أسلاك وكابلات
   - صناديق توصيل
   - إكسسوارات كهربائية
4. **الخدمات** `/services` — التوريد السريع، الدعم الفني، الأسعار التنافسية
5. **تواصل معنا** `/contact` — نموذج تواصل + بيانات الاتصال + خريطة (placeholder)

## الهوية البصرية

- **الألوان**: لوحة Ocean Deep — `#0c2340` (كحلي عميق)، `#1a4a6e` (أزرق)، `#2d8a9e` (تيل)، `#5cbdb9` (تركواز فاتح)
- **الطباعة**: Cairo للعربي (display + body)، Inter/Space Grotesk للإنجليزي
- **الأسلوب**: احترافي صناعي — بطاقات نظيفة، أيقونات خطية للمنتجات، أقسام واسعة، تباين قوي، صور hero للمنتجات الكهربائية
- **اللغة**: مبدّل عربي/إنجليزي في الـ header، RTL تلقائي للعربي

## المكونات المشتركة

- **Header**: شعار Egy Power + روابط التنقل + مبدّل اللغة + زر CTA "اطلب عرض سعر"
- **Footer**: بيانات الشركة، روابط سريعة، تواصل، حقوق النشر
- **LanguageProvider**: context لإدارة اللغة + dir تلقائي على `<html>`

## التفاصيل التقنية

- TanStack Start مع routes منفصلة لكل صفحة
- ملفات الترجمة في `src/i18n/` (ar.ts, en.ts)
- Design tokens في `src/styles.css` بصيغة `oklch` (لون primary أزرق Ocean Deep، accent تركواز)
- خط Cairo عبر Google Fonts في `__root.tsx`
- `head()` مخصص لكل route (title, description, og) بالعربي والإنجليزي
- صور توليدية للـ hero والمنتجات تُحفظ في `src/assets/`
- نموذج التواصل: واجهة فقط (بدون backend في هذه المرحلة)

## بيانات التواصل

ملاحظة: لم تُذكر بيانات تواصل محددة (هاتف/عنوان/إيميل) — سأستخدم placeholders واضحة يمكنك استبدالها لاحقاً، أو أخبرني بها لإضافتها مباشرة.

## ما هو خارج النطاق

- لا backend / database (موقع ثابت تعريفي)
- لا نظام تسجيل دخول
- لا متجر إلكتروني أو سلة شراء
- نموذج التواصل بدون إرسال فعلي (يمكن تفعيله لاحقاً عبر Lovable Cloud)
